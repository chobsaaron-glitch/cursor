# А-рама — склад багетных реек

Мобильное приложение для инвентаризации багетных реек в мастерской **«А-рама»**.

Работает как **PWA**: ставится на Android из Chrome и открывается как обычное приложение. Данные хранятся на устройстве (IndexedDB) и доступны офлайн.

## Возможности

- Учёт реек по **ячейкам склада**
- Поля: **артикул**, **длина (см)**, **количество**, **дата внесения**, **комментарий**, **фото по ссылке**
- **Справочник багета**: артикул → название и фото; при вводе артикула фото подставляется само
- **Синхронизация с Google Таблицами** (справочник + остатки)
- Быстрый поиск и фильтр по ячейке
- Корректировка остатков (+/−) при инвентаризации
- Экспорт / импорт JSON для резервной копии

## Установка APK на Android

Готовый файл: [`releases/Arama-sklad-debug.apk`](./releases/Arama-sklad-debug.apk)

1. Скопируйте APK на телефон (Telegram, диск, USB, почта).
2. Откройте файл на телефоне.
3. Разрешите установку из этого источника, если Android спросит.
4. Установите приложение **«А-рама»**.

Пересобрать APK на компьютере (нужны JDK и Android SDK):

```bash
cd arama-inventory
npm install
npm run apk
```

## Google Таблицы

Пошаговая настройка: [`google-apps-script/README.md`](./google-apps-script/README.md).

Кратко: вставьте скрипт `Code.gs` в Apps Script вашей таблицы → разверните веб-приложение → в приложении укажите URL и токен → «Синхронизировать».

## Установка как PWA (без APK)

1. Опубликуйте приложение на HTTPS.
2. На телефоне откройте сайт в **Chrome**.
3. Меню **⋮** → **«Установить приложение»**.

Для разработки:

```bash
cd arama-inventory
npm install
npm run dev
```

Сборка веба:

```bash
npm run build
npm run preview
```

## Как пользоваться

1. Заполните **Справочник** (или загрузите из Google Таблицы).
2. **Добавить рейку** — при вводе артикула фото подтянется из справочника.
3. В карточке рейки меняйте остаток кнопками **+** / **−**.
4. В разделе **Таблицы** синхронизируйте склад с Google Sheets.

## Стек

- React + TypeScript + Vite + Capacitor (Android)
