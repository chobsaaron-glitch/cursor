# Синхронизация «А-рама» ↔ Google Таблицы

Приложение обменивается данными через **Google Apps Script** (веб-приложение), привязанный к вашей таблице.

## Листы в таблице

### Справочник
| Артикул | Название | Фото | Примечание | Обновлено |
|---------|----------|------|------------|-----------|

### Остатки
| ID | Ячейка | Артикул | Длина_см | Количество | Фото | Комментарий | Создано | Обновлено |
|----|--------|---------|----------|------------|------|-------------|---------|-----------|

Листы создаются скриптом автоматически при первой синхронизации.

## Настройка (один раз)

1. Создайте [новую Google Таблицу](https://sheets.google.com).
2. **Расширения → Apps Script**.
3. Удалите код по умолчанию и вставьте содержимое [`Code.gs`](./Code.gs).
4. В строке `SYNC_TOKEN` задайте свой секретный пароль (тот же укажете в приложении).
5. Нажмите **Развернуть → Новое развёртывание**:
   - тип: **Веб-приложение**
   - выполнять от имени: **Меня**
   - у кого есть доступ: **Все**
6. Скопируйте **URL веб-приложения**.
7. В приложении «А-рама» → ⚙ → **Google Таблицы** вставьте URL и токен.
8. Нажмите **Синхронизировать**.

После этого:
- справочник багета и остатки на телефоне ↔ таблица;
- при вводе артикула в карточке рейки фото подтягивается из справочника;
- синхронизация идёт **в фоне** и отправляет только изменённые строки.

Если синхронизация была медленной, замените старый скрипт на этот `Code.gs` и сохраните проект в Apps Script (новый деплой не обязателен).
